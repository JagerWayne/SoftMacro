What is SoftMacro?

SoftMacro is a context-aware macro keyboard for Windows. Press one global hotkey and an on-screen list of shortcuts appears for whichever application is in front. Press a listed key (or click its row) and SoftMacro hides itself, returns focus to that application and replays the macro there. Different applications get different sets of macros. 

+--------------------------------------+
|  Google Chrome                       |
|  ──────────────────────────────────  |
|  Q  —  New tab                       |
|  S  —  Save page                     |
|  G  —  Tabs            (3 items)     |
+--------------------------------------+

Everything is managed in a local web UI — no account, no cloud, no internet needed. Macros are stored per executable in %APPDATA%\SoftMacro\apps\<exe>.json.

Quick start

  1. Open the web UI at http://localhost:{{ web_port }} (the exact address is printed when SoftMacro starts).
  2. Add an application. On the Apps page click + New app and pick one of your running windows, or type the executable name (for example chrome.exe) and a display name.
  3. Create a macro. Open the app and click + New macro. Give it a name and add events — either type a command in Quick Add (for example Ctrl+T) or use the Command builder. Click Create macro.
  4. Assign it to a key. On the app page, click a key on the on-screen keyboard, choose the macro (or a group) from the popover. The key lights up with the macro name.
  5. Use it. Focus the application, press {{ hotkeys.show_overlay }}, then press the assigned key.

The overlay (macro keyboard)

The overlay is a frameless, semi-transparent window that covers the screen. It lists only the keys that are actually assigned for the foreground application, in keyboard order (letters, then F-keys, then numpad).

What you doWhat happens
Press an assigned keyPlays that macro in the app you came from (or opens the group).
Click a rowSame as pressing its key.
Press EscSteps back one group level; at the top level it closes the overlay.
Press the show hotkey againCloses the overlay (toggle).
Do nothingThe overlay stays until you close it. It always sits on top.

While the overlay is open, Esc is captured globally, so it always reaches SoftMacro — even if the window did not get keyboard focus. Groups show their name in the subtitle, tinted with the group colour, with the full trail (Tabs › Advanced › Deep) as you go deeper.

If the overlay is empty, no macros are assigned to the application that had focus when you pressed the hotkey. The title bar always shows which app the overlay is for, so you can tell.

How to change a hotkey

  1. Open Settings.
  2. Type the combination in the field (or click the key chips — click a hotkey field first, then click keys to build the combo; Clear empties it).
  3. Click Save all settings. It applies immediately — no restart.

A combination is written as modifier+modifier+key:

  • Modifiers come from: ctrl, alt, shift, win.
  • Modifiers may be in any order: ctrl+shift+r = shift+ctrl+r.
  • It is case-insensitive: CTRL+Z = ctrl+z.
  • There must be exactly one non-modifier key: ctrl+shift alone is invalid.
  • Multi-word keys use spaces: ctrl+page down, alt+print screen.
  • Unknown names are rejected when you save (for example ctrl+foo).

Windows reserves some combinations: Ctrl+Alt+Delete is handled by the operating system before any application can see it, and combinations like Ctrl+Shift+Esc may also trigger their built-in Windows action. Prefer combinations that are not used by Windows or by the target application.

Macros & Quick Add

A macro is a named list of timed events (key presses, mouse actions and waits) that is replayed exactly as recorded. Macros belong to one application and can be assigned to as many keys as you like (in the main keyboard or inside groups).

The macro form

FieldWhat it does
NameShown in the overlay and on the app page.
RepeatHow many times the macro plays back-to-back (1–999).
SpeedPlayback multiplier: 0.5 = half speed, 2 = twice as fast.
Quick AddType a command, press Enter (or Add), and its events are appended.
Per-event delayMilliseconds added between events created by Quick Add (default 50).
Command builderClickable keys and input boxes that build commands for you.
Events tableEvery event with its timestamp, type and payload — editable and deletable.
Raw JSONThe exact stored format, kept in sync with the table.

Quick Add commands

Commands are case-insensitive. Each one expands to one or more events, placed at “last event time + per-event delay”. A few examples: 

Ctrl+T              press Ctrl+T
Type "hello"        type the text hello
Wait 500            pause for 500 ms
Click 500 300       move to (500,300) and left-click
Move 100 200        move the cursor to (100,200)
Scroll down 3       scroll down three steps
Hold shift          press and keep Shift held
Release shift       release the held Shift

Playing, testing and stopping

  • Play: press the overlay hotkey, then the assigned key. SoftMacro restores focus to the application you came from and waits a moment before replaying, so the macro lands in the right place.
  • Test: the ▶ Test button on a macro card runs a 3-2-1 countdown so you can switch to the target window; press Esc or click the countdown to cancel.
  • Stop: press {{ hotkeys.stop_playback }} while a macro is playing to cancel it immediately.

Events table and raw JSON

Each event is [timestamp_ms, [kind, payload]]:

[
  [0,  ["key_down", "Key.ctrl_l"]],
  [12, ["key_down", "t"]],
  [28, ["key_up",   "t"]],
  [40, ["key_up",   "Key.ctrl_l"]],
  [90, ["delay",    500]],
  [590, ["mouse_move", [500, 300]]],
  [600, ["mouse_down", "left"]],
  [620, ["mouse_up",   "left"]]
]

Valid event kinds: key_down, key_up, mouse_down, mouse_up, mouse_move, scroll, delay. The timestamp is milliseconds from the start of the macro; events play in that order.

Groups (nested)

Groups are sub-keyboards: a key can open a group instead of playing a macro, and groups can contain further groups to any depth. This lets you fit far more than 26 shortcuts into one app.

  1. On an app page click + Group. It is created inside the directory you are viewing and is automatically bound to the first free key there.
  2. Open the group with Open › (or the breadcrumb). Inside, assign macros to keys just like at the top level.
  3. Use + Group again inside a group to nest deeper. The breadcrumb (Main › Tabs › Advanced) always shows where you are and lets you jump back up.
  4. In the overlay, press the group's key to descend. The subtitle shows the trail, tinted with the current group's colour. Esc goes back one level.
  • Groups have a name and a colour (used in the UI and the overlay subtitle).
  • A key assignment is unique per directory: the same key can be free in one group and assigned in another.
  • Self-references and cycles (A inside B inside A) are rejected.
  • Deleting a group removes the keys that opened it and clears references from other groups.

Security

The web UI can inject keystrokes, so it is deliberately locked down:

  • It listens on 127.0.0.1 only — never on the network.
  • Non-loopback Host headers are rejected (DNS rebinding), and state-changing requests from foreign origins are rejected (CSRF).
  • Responses carry a Content-Security-Policy and related headers; Flask debug mode is off.
  • Updates come only from the official GitHub repository over HTTPS, with archive validation and a strict file allow-list.

Troubleshooting

ProblemWhat to try
The hotkey does nothing The combination may be taken by Windows or the active app. Change it on the Settings page; if you target elevated (administrator) apps, run SoftMacro as administrator too.
The overlay is empty No macros are assigned for the app that had focus. Check the app name in the overlay title and assign keys on that app's page.
A macro types the wrong characters Macros replay physical keys, not text. The Type command handles capitals, but symbols follow the active keyboard layout.
A macro doesn't play in a game/app Elevated apps and games with anti-cheat ignore injected input. Run SoftMacro at the same privilege level as the target.
The web UI won't open Check the address printed at startup; if the port is busy, pick another on Settings → Web UI (or restart the server from the tray).
Update check fails It needs an internet connection to GitHub. Offline machines simply stay on the current version.
The tray icon is missing Start with run.bat once and check the console output; some setups block tray icons until first run.
Antivirus complains SoftMacro uses a global keyboard hook and simulated input — the same techniques as any macro tool. Allow it if you trust the source.

Uninstalling

  1. Untick Start SoftMacro automatically on the Settings page.
  2. Exit SoftMacro from the tray menu.
  3. Delete the SoftMacro folder and, if you want a clean slate, %APPDATA%\SoftMacro.
